## Configuration

Settings come from flags, environment variables, and `config.yaml` (see [config.example.yaml](config.example.yaml)).

<!-- configulator:begin -->

| Key                             | Type           | Default                             | Environment                     | Flag                              | Description                                                                                               |
|---------------------------------|----------------|-------------------------------------|---------------------------------|-----------------------------------|-----------------------------------------------------------------------------------------------------------|
| `log-level`                     | string         | `info`                              | `LOG_LEVEL`                     | `--log-level`                     | Logging level for the application. One of debug, info, warn, or error                                     |
| `port`                          | integer        | `8080`                              | `PORT`                          | `--port`                          | Port to listen on                                                                                         |
| `mqtt.broker`                   | string         |                                     | `MQTT_BROKER`                   | `--mqtt.broker`                   | MQTT broker address                                                                                       |
| `mqtt.client-id`                | string         | `wheresmyscope`                     | `MQTT_CLIENT_ID`                | `--mqtt.client-id`                | Client ID for MQTT connection                                                                             |
| `mqtt.prefix`                   | string         | `wheresmyscope`                     | `MQTT_PREFIX`                   | `--mqtt.prefix`                   | Prefix for MQTT topics                                                                                    |
| `mqtt.username`                 | string         |                                     | `MQTT_USERNAME`                 | `--mqtt.username`                 | Username for MQTT connection                                                                              |
| `mqtt.password`                 | string         |                                     | `MQTT_PASSWORD`                 | `--mqtt.password`                 | Password for MQTT connection (secret)                                                                     |
| `image.projection`              | string         | `STG`                               | `IMAGE_PROJECTION`              | `--image.projection`              | Projection type                                                                                           |
| `image.fov`                     | number         | `3.3`                               | `IMAGE_FOV`                     | `--image.fov`                     | Field of view in degrees                                                                                  |
| `image.format`                  | string         | `png`                               | `IMAGE_FORMAT`                  | `--image.format`                  | Image format                                                                                              |
| `image.width`                   | integer        | `900`                               | `IMAGE_WIDTH`                   | `--image.width`                   | Image width in pixels                                                                                     |
| `image.height`                  | integer        | `600`                               | `IMAGE_HEIGHT`                  | `--image.height`                  | Image height in pixels                                                                                    |
| `image.stretch`                 | string         | `linear`                            | `IMAGE_STRETCH`                 | `--image.stretch`                 | Stretch type                                                                                              |
| `image.min-cut`                 | number         | `0.5`                               | `IMAGE_MIN_CUT`                 | `--image.min-cut`                 | Minimum cut value for image processing                                                                    |
| `image.max-cut`                 | number         | `99.5`                              | `IMAGE_MAX_CUT`                 | `--image.max-cut`                 | Maximum cut value for image processing                                                                    |
| `image.hips`                    | string         | `CDS/P/DSS2/color`                  | `IMAGE_HIPS`                    | `--image.hips`                    | HIPS name for the image                                                                                   |
| `cors-allowed-origins`          | list of string | `https://*,http://*`                | `CORS_ALLOWED_ORIGINS`          | `--cors-allowed-origins`          | CORS allowed origins                                                                                      |
| `public-frame.stacker-url`      | string         |                                     | `PUBLIC_FRAME_STACKER_URL`      | `--public-frame.stacker-url`      | astro-stacker's base URL, e.g. http://astro-stacker.astro-processing:8080; empty shows only survey images |
| `public-frame.public-url`       | string         | `https://wheresmyscope.mcswain.dev` | `PUBLIC_FRAME_PUBLIC_URL`       | `--public-frame.public-url`       | This service's public base URL, which the page loads the frame from                                       |
| `public-frame.interval-seconds` | integer        | `60`                                | `PUBLIC_FRAME_INTERVAL_SECONDS` | `--public-frame.interval-seconds` | Seconds between checks for a newer frame                                                                  |
| `public-frame.timeout-seconds`  | integer        | `10`                                | `PUBLIC_FRAME_TIMEOUT_SECONDS`  | `--public-frame.timeout-seconds`  | Seconds before a fetch from the stacker gives up and the survey image is shown                            |

<!-- configulator:end -->
